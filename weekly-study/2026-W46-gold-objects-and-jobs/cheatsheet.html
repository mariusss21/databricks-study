Databricks · Associate cert

Mon 9 Nov deep dive * + docs
Declare the grain, write idempotently, let Delta enforce what it can.
  • INSERT … REPLACE WHERE: atomically overwrites rows matching a predicate ✓
  • NOT NULL / CHECK: enforced; a violation fails the whole transaction ✓
  • PK / FK: informational, not enforced; can help the optimizer ✓
  • Liquid clustering (CLUSTER BY): replaces partitioning + ZORDER; keys changeable ✓
Expectations — action on a bad record ✓
EXPECT (warn, default)row written, metric logged
… ON VIOLATION DROP ROWrow dropped, count logged
… ON VIOLATION FAIL UPDATEupdate fails, rolled back
Exam traps
  • Empty SELECT + REPLACE WHERE → matching rows may be deleted ✓
  • Clustering is not compatible with PARTITIONED BY or ZORDER; max 4 keys ✓
  • count(col) skips NULLs; approx_count_distinct = HLL++, ~5 % default ✓

A nightly LLM step: cap the input, batch it, retry by error class, log raw.
  • request_hash: one key = idempotency, cache, batch custom_id, replay ◦
  • Effective length: longest input where your eval still passes, not the window ◦
  • Lost in the middle: accuracy dips for evidence mid-context (U-curve) ◦
  • Context rot: quality falls as input grows; focused input wins ◦
  • Raw response log: append-only params + raw output + usage, by hash + run ◦

Data Eng · US senior interviews

Fri 13 Nov deep dive
Correct · fast · watched: three parts of one Gold promise.
  • Data contract: grain, keys, constraints, SLA in measurable terms ◦
  • SLI / SLO / SLA: what you measure / internal target / promise to the consumer ◦
  • 5 pillars: freshness · volume · schema · distribution · lineage ◦
  • Skew: max task ≫ median in Spark UI; all slower = growth ◦
  • Salting: random suffix on a hot key; last resort after AQE + broadcast ◦
  • Blast radius: system.access.table_lineage → who reads the table ◦
Gotchas
  • Drop bad rows in Silver; stop on a bad table in Gold ◦
  • AQE skew join splits joins only, not a skewed repartition before a write ◦
  • Partition by a skewed key → one giant partition + tiny files ◦
  • Quality gate gets 0 retries: bad data won't fix itself ◦
  • Duration warning, not failure alert, is the SLA alarm ◦
Recall: the 6-link chain · REPLACE WHERE vs MERGE vs MV.
