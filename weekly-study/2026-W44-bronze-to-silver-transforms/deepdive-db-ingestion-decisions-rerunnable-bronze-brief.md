## Topics
1. Choosing the ingestion tool (the Fri Oct 23 topic): Lakeflow Connect, which is managed ingestion for SaaS and database sources Databricks supports and shifts ownership of operations to the platform. Auto Loader is for when files land in your bucket or volume. COPY INTO handles idempotent batch file loads. JDBC, ODBC, or REST reads from a notebook are an allowed path too, usually scheduled as a Lakeflow Job (Mon Oct 19, Thu Oct 22). The pill's rule of thumb is to decide based on who owns the extract and how often the schema changes, not on which Spark read API feels familiar.
2. Exactly-once and re-runs with Auto Loader (Tue Oct 20): the checkpoint remembers which files were already processed, so a restart doesn't load them twice. Triggers come next: `availableNow` processes the backlog and then stops, while continuous keeps running.
3. Shape and drift in Bronze (Wed Oct 21, Sat Oct 24): nested or semi-structured JSON lands raw in Bronze as string, struct, or VARIANT, inside a Unity Catalog Delta table and not only as raw files. Schema evolution either adds new columns or keeps unexpected fields in the rescued-data column instead of failing the load (Oct 19 knowledge pill). Bronze table design: keep it append-only and add the `_metadata` file columns (source file name) and an ingest timestamp, so any later Silver row can be traced back to its payload.

## How they connect
The Sunday recap topic was "an end-to-end Bronze pipeline that's safe to re-run," and these three topics are its three decisions. First you pick the tool that fits the source (topic 1). Then the checkpoint or idempotency guarantees that a re-run doesn't duplicate data (topic 2). Last, the Bronze schema and metadata columns make sure a change in the data's shape doesn't break the load, and that every row can be audited (topic 3). NJ's DE track that week covered the general "why" behind each one: CDC goes with Connect, delivery semantics with checkpoints, schema drift with VARIANT and rescued data, and dedup and replay with append-only Bronze.
