# Databricks Certified Data Engineer Associate

**Status:** In progress

Eight-week plan for the Databricks Certified Data Engineer Associate exam. Target window: **January 12–14, 2027**. Official guide: [Databricks Certified Data Engineer Associate](https://www.databricks.com/learn/certification/data-engineer-associate).

## The 8-week plan

| Week | Starts | Focus |
|---|---|---|
| W1 | Nov 16, 2026 | Foundations: Delta/ACID, lakehouse, compute, Unity Catalog managed vs external |
| W2 | Nov 23, 2026 | Ingestion: COPY INTO, Auto Loader, Lakeflow Connect |
| W3 | Nov 30, 2026 | Bronze to Silver, data quality, star schema and SCDs |
| W4 | Dec 7, 2026 | Gold and Lakeflow Declarative Pipelines, Spark UI tuning |
| W5 | Dec 14, 2026 | Lakeflow Jobs, troubleshooting |
| W6 | Dec 21, 2026 | Governance (light) |
| W7 | Dec 28, 2026 | CI/CD with Git folders, Bundles, CLI (light) |
| W8 | Jan 4, 2027 | Mocks and review |

## Weekly rhythm

- **Monday:** review quiz and a one-page cheat sheet.
- **Tuesday–Thursday:** one 15–20 minute pill.
- **Friday:** a 40–60 minute scenario deep dive.
- **Evenings:** recall checks.
- **Misses:** tracked by exam section in [misses.md](misses.md).
